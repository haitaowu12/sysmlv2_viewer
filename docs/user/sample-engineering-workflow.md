# Sample Engineering Workflow

Use `fixtures/workspaces/phase5-infrastructure`.

1. Open the four-document workspace and confirm the qualified authority.
2. In Problems, inspect the intentional unresolved reference.
3. Select **Traceability** and follow a requirement to its satisfying element.
4. In **Verification**, identify direct coverage gaps.
5. In **Interfaces**, inspect endpoint, ownership, requirement-basis, and
   verification findings.
6. Use the native editor to propose the interface change; review source edits,
   diagnostics, affected identities, and semantic diff before approval.
7. In **Changes**, compare the two Git baselines and confirm rename/change
   classification uses stable identity.
8. In **Reviews**, create a baseline-scoped finding, disposition it, check
   staleness, and close the review.
9. In **Reports**, generate workspace-health, requirement-coverage,
   verification-readiness, interface-register, interface-quality, semantic
   change, findings, closure, and baseline-manifest evidence as applicable.
10. Optionally use **Assistant** for a cited proposal; confirm source remains
    unchanged until separate user approval.

This fixture is executable acceptance evidence, not a claim that every SysML
construct or interface attribute is supported.
