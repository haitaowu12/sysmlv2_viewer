# Apollo 11 example

`apollo-11.modeling.json` is the complete Modeling Lab review project exported during the 2026-10-15 Apollo exercise. It preserves all 28 original SysML source files, five core views and two custom views, together with the original source-file mapping and source-basis notes.

Source: [Airbus Apollo 11 SysML v2 research model](https://github.com/airbus/apollo-11-sysml-v2/tree/c545dbffebc4d20f61bd29262f459ec9d0c301a8), upstream revision `c545dbffebc4d20f61bd29262f459ec9d0c301a8`. The recorded source provenance inside the project is authoritative for this snapshot. This is an illustrative, incomplete research scaffold; it does not establish approved Apollo design, verification, or acceptance.

The Open model action validates this project through the same atomic project-opening path as a user-selected saved project. Keep the example available at `./examples/apollo-11.modeling.json` in native and browser distributions.
