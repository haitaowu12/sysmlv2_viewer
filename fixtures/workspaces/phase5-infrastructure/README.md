# Phase 5 infrastructure assurance pilot

This source-canonical multi-file workspace represents a regional telemetry and
control boundary shared by a control centre, remote station, and network
carrier. It intentionally contains incomplete requirement and verification
coverage. The qualification script injects one unresolved legacy gateway type
into its disposable working copy for diagnostic and review qualification.

The qualification script creates two Git baselines in a disposable copy. It
does not write baseline, review, or generated report state into this fixture.
